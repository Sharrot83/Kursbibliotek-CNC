Formler för sinus, cosinus, tangens och cotangens, samt tabell för vilken formel du ska använda beroende på vad du känner till och vad du söker. Denna sida kan hållas öppen i en egen flik medan du räknar.

TRIGONOMETRI

Sinus

sin α = a / c
sin β = b / c

Cosinus

cos α = b / c
cos β = a / c

Tangens

tan α = a / b
tan β = b / a

Cotangens

cot α = b / a
cot β = a / b
α + β = 90°
Cotangens används sällan vid tekniska beräkningar.

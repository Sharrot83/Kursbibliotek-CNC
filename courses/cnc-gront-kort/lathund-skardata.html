Skärdata — Fräsning, svarvning, borrning

Riktvärden för skärhastighet och matning per materialgrupp, med formler och miniräknare för respektive bearbetning. Siffrorna är avskrivna från Verkstadshandboken (snabbstål/HSS-tabeller) — stäm alltid av mot maskinens och verktygstillverkarens egna rekommendationer.

1Skärhastighet (Vc)

Vc = (n × π × d) / 1000
Vc = skärhastighet (m/min)  ·  n = varvtal (varv/min)  ·  d = verktygsdiameter (mm)

2Varvtal (n)

n = (Vc × 1000) / (π × d)
Samma formel omskriven — den du oftast räknar med: du vet skärhastigheten verktyget/materialet klarar, och vill veta varvtalet.

3Bordsmatning (Vf)

Vf = fz × Zn × n
Vf = bordsmatning (mm/min)  ·  fz = matning per tand (mm/tand)  ·  Zn = antal tänder  ·  n = varvtal (varv/min)

1Skärhastighet (Vc)

Vc = (n × π × D) / 1000
Vc = skärhastighet (m/min)  ·  n = varvtal (varv/min)  ·  D = arbetsstyckets diameter (mm) — vid svarvning är det alltså detaljens diameter, inte verktygets

2Varvtal (n)

n = (Vc × 1000) / (π × D)
Kom ihåg att D minskar när du svarvar av material — varvtalet behöver då höjas för att hålla samma Vc, om inte maskinen har konstant skärhastighet (CSS) inställd.

3Matningshastighet (Vf)

Vf = f × n
Vf = matningshastighet (mm/min)  ·  f = matning (mm/varv)  ·  n = varvtal (varv/min)
